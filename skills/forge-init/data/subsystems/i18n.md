# Internationalization Subsystem (i18n)

## Requires

None — i18n is independent.

## Imports (config.go)

```go
"github.com/dmitrymomot/forge/pkg/i18n"
```

## Imports (main.go)

```go
"github.com/dmitrymomot/forge/pkg/i18n"

i18ntranslations "{{MODULE_PATH}}/i18n/translations"
```

## Config Field

```go
I18n i18n.Config `envPrefix:"I18N_"`
```

## Init Code

```go
i18nSvc, err := i18n.New(cfg.I18n, i18n.WithJSONDir(i18ntranslations.FS))
if err != nil {
    log.Fatal("failed to init i18n: ", err)
}
```

**Note:** `i18ntranslations.FS` is an `embed.FS` from the `i18n/translations/` package containing JSON translation files organized as `{lang}/{namespace}.json`.

## Health Check

None.

## App Option

```go
forge.WithMiddleware(middlewares.I18n(i18nSvc, middlewares.I18nConfig{Namespace: "app"})),
```

**Note:** The `middlewares` package is already imported in the base main.go template. The `Namespace` matches the default translation file name (`app.json`).

## Generated Files

When `i18n` is selected, generate the following files from `templates/i18n-init.md`:

| File | Purpose |
|------|---------|
| `i18n/translations/embed.go` | Embed package exposing translation files as `embed.FS` |
| `i18n/translations/en/app.json` | Starter English translations |

These files are created during **Phase 1** (directory structure creation).

## Notes

- i18n is independent and does not require other subsystems.
- Translations are embedded via `i18n/translations/embed.go` using the same pattern as `db/migrations/embed.go`.
- Translation files follow the convention `{lang}/{namespace}.json` (e.g., `en/app.json`, `es/app.json`).
- To add a new language, create a directory (e.g., `i18n/translations/es/`) and add `app.json` with the same keys.
- The i18n middleware resolves language from cookies (`lang`) and `Accept-Language` header, then stores a `Translator` in context.
- In handlers: `c.T("key")` for simple translations, `c.Tn("key", n)` for pluralized translations.
- Placeholders: `c.T("greeting", i18n.M{"name": "World"})` for `"Hello, {{name}}!"`.
- `forge.GetTranslator(c)` returns the full `*i18n.Translator` for advanced use.
- `forge.GetLanguage(c)` returns the resolved language string.
